# Contributing to the BOSC Website

Thank you for helping improve the Bugema Open Source Community website.

## Good first contributions
- Improve clarity, grammar, accessibility, or mobile layout.
- Fix a broken link or add verified community information.
- Improve the project summaries using each project's own README.
- Add confirmed events, with organizer approval and accurate dates.
- Improve documentation and testing instructions.

## Workflow
1. Open an issue describing the proposed change.
2. Create a branch for the change.
3. Keep changes focused and test the page on desktop and mobile widths.
4. Check links, headings, alt text, and keyboard navigation.
5. Open a pull request explaining what changed and how it was tested.

## Content guidelines
- Do not invent event dates, partnerships, metrics, endorsements, or project status.
- Keep descriptions inclusive, accurate, and understandable to newcomers.
- Confirm permission before publishing personal contact details or photographs.
- Preserve existing files and repository history; never force-push to shared branches.

## Local testing
Open `index.html` in a browser and inspect responsive behavior, navigation, links, and the browser console.
